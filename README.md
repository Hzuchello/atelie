# Aurélia Atelier — protótipo de vitrine

Site one-page de uma maison fictícia de lingerie contemporânea, pensada para o mercado brasileiro premium.

Abrir `index.html` no navegador. Não precisa de servidor.

## O que o protótipo demonstra

- Identidade de atelier (não de magazine): serifada editorial + sans limpa, paleta ivory / vinho / ouro velho
- Hero em tela cheia com CTA mínimo — tendência 2026 de luxury ecommerce
- Navegação slim que ganha linha ao rolar
- Grid misto (peças hero ocupam 2 colunas) em vez de catálogo uniforme
- Filtro por coleção a partir dos cards editoriais
- Página de produto em modal com construção, caimento e envio discreto
- Sacola lateral com embalagem discreta marcada por padrão
- Quiz de medidas sem foto (privacy-first), o maior alavanca de conversão no nicho
- Promessas de serviço: caixa neutra, troca 30 dias, grade 32–46 / A–G, origem em Curitiba
- Lista privada / pré-venda
- Mobile-first, tipografia grande, botões no alcance do polegar
